# Вимоги та змінні

Обладнання, програмне забезпечення та облікові записи, потрібні перед початком, і всі плейсхолдери, що використовуються в документації. Під час копіювання команд замінюйте плейсхолдери власними значеннями.

## Обладнання

| Пункт | Мінімум | Комфортно |
|---|---|---|
| CPU | 2 ядра, x86_64 або arm64 | 4+ ядра |
| RAM | 4 ГБ (лише K3s займає близько 1 ГБ) | 16 ГБ+ (кілька проєктів, моніторинг) |
| Диск | 40 ГБ SSD | 250 ГБ+ SSD |
| Мережа | Дротовий Ethernet | Дротовий Ethernet, роутер із DHCP-резервуванням |

Для сервера краще Ethernet, ніж Wi-Fi (див. [Усунення проблем із мережею](../99-appendix/troubleshooting-networking.md)).

## Програмне забезпечення та облікові записи

- USB-флешка для встановлення (8 ГБ+) та інструмент для запису ISO, для локального обладнання; або VPS з образом Ubuntu Server LTS.
- Ноутбук із терміналом і `ssh` (macOS або Linux), а також IDE з підтримкою Remote-SSH.
- Обліковий запис на Git-хостингу (GitHub або GitLab) для коду; по одному на кожну особистість, якщо ви розділяєте робоче та особисте.
- Опційно: VPS із публічною IP-адресою (віддалений доступ), зареєстрований домен (публічні сайти), реєстр контейнерів.

## Плейсхолдери

| Плейсхолдер | Значення | Приклад |
|---|---|---|
| `<SERVER_USER>` | Користувач із sudo (не root) на сервері | `dev` |
| `<SERVER_HOSTNAME>` | Ім'я хоста сервера | `devbox` |
| `<SERVER_IP>` | Адреса сервера в LAN (або публічна IP-адреса VPS) | `192.168.1.50` |
| `<SSH_PORT>` | Нестандартний порт SSH, обраний під час захисту | `2222` |
| `<DOMAIN_BASE>` | Базовий домен або локальний суфікс для імен хостів проєктів | `devbox.local`, `example.com` |
| `<PROJECT_NAME>` | Коротка назва проєкту малими літерами, використовується для папки, namespace та імені хоста | `blog` |
| `<VPS_IP>` | Публічна IP-адреса VPS-шлюзу | `203.0.113.10` |
| `<GIT_WORK_EMAIL>` | E-mail для робочих комітів | `me@work.example` |
| `<GIT_PERSONAL_EMAIL>` | E-mail для особистих комітів | `me@home.example` |
| `<DB_PASSWORD>` | Пароль бази даних, який ви генеруєте (`openssl rand -base64 24`) | не зберігається в репозиторії |
| `<PROJECT_GROUP>` | Каталог, що групує проєкти (компанія, клієнт, `personal`) | `personal` |
| `<DB_NAME>` | Назва бази даних | `wordpress` |
| `<OLD_DOMAIN>` | Домен сайту, що мігрує | `old.example.com` |
| `<GIT_USER_NAME>` | Ім'я для комітів Git | `Jane Doe` |
| `<ORG>`, `<REPO>` | Організація/користувач Git і назва репозиторію | `acme`, `blog` |
| `<VPS_USER>` | Адміністративний користувач на VPS-шлюзі | `admin` |
| `<TUNNEL_USER>`, `<TUNNEL_PORT>` | Обмежений користувач на VPS і порт, який слухає тунель | `tunnel`, `2200` |
| `<GRAFANA_ADMIN_PASSWORD>`, `<SAMBA_PASSWORD>` | Паролі, які ви генеруєте | не зберігаються в репозиторії |

Правила іменування: `<PROJECT_NAME>` має бути коректною назвою Kubernetes (малі літери, цифри, `-`). Тримайте її однаковою в каталозі коду, каталозі маніфестів, namespace та імені хоста.
