# Відмінності локального та хмарного середовища

Той самий стек працює на домашньому міні-ПК або на хмарному VPS. Ця сторінка перелічує відмінності та кроки, які слід пропустити чи адаптувати.

## Порівняння

| Аспект | Домашній міні-ПК | Хмарний VPS |
|---|---|---|
| Встановлення ОС | USB-флешка, інсталятор на консолі | Вибрати образ Ubuntu Server LTS у панелі провайдера |
| Адреса | Адреса LAN від роутера; потрібне DHCP-резервування або статична конфігурація netplan | Публічна статична IP-адреса від провайдера |
| Роутер | Потрібен: резервування, за потреби переадресація портів | Немає |
| Брандмауер | UFW на хості; NAT роутера додає ще один шар | UFW на хості плюс хмарний брандмауер провайдера (відкрийте ті самі порти в обох) |
| Wi-Fi | Можливий, але використовуйте Ethernet | Не застосовується |
| Доступ | З LAN напряму; ззовні лише через VPS-шлюз або переадресацію портів | Напряму через інтернет, SSH лише за ключем |
| DNS і домени | Записи в `/etc/hosts` або локальний DNS (імена `*.local`) | Справжні DNS A-записи, що вказують на IP VPS; можливі TLS-сертифікати |
| Живлення і вартість | Купівля обладнання, електроенергія, UPS опційно; працює 24/7 з малим споживанням | Щомісячна плата залежно від CPU/RAM; без обладнання |
| Ризик експозиції | Низький, якщо порти не переадресовано | Високий з першої хвилини: боти скануватимуть нові IP, захищайте сервер перш за все інше |
| Ресурси | Обмежені вашим обладнанням | Можна змінювати |
