# Глосарій

| Термін | Значення |
|---|---|
| ClusterIP | Типовий тип Service: віртуальна IP-адреса, доступна лише всередині кластера |
| ConfigMap | Об'єкт Kubernetes для несекретної конфігурації, що монтується як файли або змінні середовища |
| Container (контейнер) | Ізольований процес, запакований разом із залежностями, що запускається з образу |
| containerd | Середовище виконання контейнерів, яке K3s використовує для запуску Pod |
| CNI | Container Network Interface: плагін, що надає Pod доступ до мережі (у K3s це Flannel) |
| Deployment | Об'єкт, що підтримує потрібну кількість однакових Pod і керує оновленнями |
| DHCP reservation (резервування DHCP) | Налаштування роутера, що завжди видає ту саму IP-адресу локальної мережі певній MAC-адресі |
| Docker | Інструмент для збирання образів і запуску контейнерів |
| ed25519 | Сучасний тип ключа SSH; короткий і надійний |
| Fail2ban | Служба, що банить IP-адреси після повторних невдалих входів, читаючи логи |
| Flannel | Типовий плагін CNI в K3s, що забезпечує мережу Pod |
| Grafana | Вебінтерфейс для дашбордів, побудованих на даних Prometheus і Loki |
| Helm | Менеджер пакетів для Kubernetes; встановлює застосунки як версіоновані чарти |
| Helm chart (чарт Helm) | Пакет маніфестів Kubernetes із параметрами, що налаштовуються |
| hostPath | Тип тому, що монтує теку вузла в Pod |
| HWE | Hardware Enablement: новіший стек ядра для випуску Ubuntu LTS |
| Image (образ) | Шаблон лише для читання, з якого запускається контейнер |
| Ingress | Об'єкт, що визначає правила HTTP-маршрутизації від імен хостів/шляхів до Service |
| includeIf | Директива конфігурації Git, що підвантажує додаткові налаштування залежно від шляху репозиторію |
| K3s | Полегшений дистрибутив Kubernetes, один виконуваний файл, містить Traefik |
| kubeconfig | Файл з адресою кластера та обліковими даними для `kubectl` (`~/.kube/config`) |
| kubectl | Клієнт командного рядка для API Kubernetes |
| Kubernetes (K8s) | Система, що розподіляє та контролює контейнери на кількох машинах |
| Loki | Система зберігання логів від Grafana Labs з індексацією за мітками |
| LTS | Реліз із довгостроковою підтримкою (Ubuntu LTS отримує оновлення безпеки п'ять років) |
| Manifest (маніфест) | YAML-файл, що описує об'єкти Kubernetes |
| Namespace (простір імен) | Логічний розділ кластера; імена та квоти діють у межах простору імен |
| netplan | Інструмент мережевої конфігурації Ubuntu, що керується YAML у `/etc/netplan/` |
| Node (вузол) | Машина в кластері; тут єдиний сервер |
| Ollama | Інструмент для локального запуску великих мовних моделей |
| Pod | Найменша одиниця розгортання: один або кілька контейнерів зі спільною мережею та томами |
| Prometheus | База даних часових рядів, що збирає й зберігає метрики |
| Promtail | Агент, що надсилає логи контейнерів і системи до Loki |
| ProxyJump | Параметр SSH (`-J`), що підключає до цільової машини через проміжний хост |
| PV / PVC | PersistentVolume і PersistentVolumeClaim: сховище та запит Pod на нього |
| Remote-SSH | Функція IDE, що відкриває й редагує теку на віддаленій машині через SSH |
| Reverse SSH tunnel (зворотний SSH-тунель) | З'єднання, яке сервер відкриває до VPS і яке відкриває порт сервера на VPS |
| rfkill | Утиліта, що показує й перемикає апаратні та програмні блокування радіомодулів |
| Samba (SMB) | Протокол і сервер мережевих спільних ресурсів, доступних з macOS і Linux |
| Secret | Об'єкт Kubernetes для чутливих значень, як-от паролі |
| Service | Стабільна внутрішня адреса та балансувальник навантаження перед набором Pod |
| SFTP | Передавання файлів через SSH |
| sshd_config | Файл конфігурації сервера OpenSSH (`/etc/ssh/sshd_config`) |
| Starship | Крособолонкова підказка командного рядка, що показує git, Kubernetes та інший контекст |
| systemd | Система ініціалізації та менеджер служб; запускає юніти, як-от служба тунелю |
| Traefik | Ingress-контролер/зворотний проксі, що входить до K3s |
| UFW | Uncomplicated Firewall: надбудова над iptables/nftables |
| VPS | Віртуальний приватний сервер, орендований у хмарного провайдера, зазвичай із фіксованою публічною IP-адресою |
| YAML | Формат даних на основі відступів, що використовується для маніфестів і netplan |
