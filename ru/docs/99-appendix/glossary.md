# Глоссарий

| Термин | Значение |
|---|---|
| ClusterIP | Тип Service по умолчанию: виртуальный IP, доступный только внутри кластера |
| ConfigMap | Объект Kubernetes с несекретной конфигурацией, монтируется как файлы или переменные окружения |
| Container | Изолированный процесс с зависимостями, запускаемый из образа |
| containerd | Container runtime, которым K3s запускает Pod |
| CNI | Container Network Interface: плагин, дающий Pod доступ к сети (в K3s это Flannel) |
| Deployment | Объект, поддерживающий нужное число одинаковых Pod и управляющий обновлениями |
| DHCP-резервирование | Настройка роутера, всегда выдающая один и тот же LAN IP заданному MAC-адресу |
| Docker | Инструмент для сборки образов и запуска контейнеров |
| ed25519 | Современный тип SSH-ключа: короткий и стойкий |
| Fail2ban | Сервис, банящий IP после повторных неудачных входов по логам |
| Flannel | CNI-плагин K3s по умолчанию, обеспечивает сеть Pod |
| Grafana | Веб-интерфейс дашбордов по данным Prometheus и Loki |
| Helm | Менеджер пакетов для Kubernetes; ставит приложения как версионируемые чарты |
| Helm chart | Пакет Kubernetes-манифестов с настраиваемыми значениями |
| hostPath | Тип volume, монтирующий каталог узла в Pod |
| HWE | Hardware Enablement: более новый стек ядра для LTS-релиза Ubuntu |
| Image | Неизменяемый шаблон, из которого запускается контейнер |
| Ingress | Объект с правилами HTTP-маршрутизации от имён хостов и путей к Service |
| includeIf | Директива конфига Git, подключающая настройки в зависимости от пути репозитория |
| K3s | Облегчённый дистрибутив Kubernetes в одном бинарнике, включает Traefik |
| kubeconfig | Файл с адресом кластера и учётными данными для `kubectl` (`~/.kube/config`) |
| kubectl | Консольный клиент API Kubernetes |
| Kubernetes (K8s) | Система, которая планирует и контролирует контейнеры на нескольких машинах |
| Loki | Хранилище логов от Grafana Labs с индексацией по меткам |
| LTS | Релиз с долгосрочной поддержкой (Ubuntu LTS получает обновления безопасности пять лет) |
| Manifest | YAML-файл с описанием объектов Kubernetes |
| Namespace | Логическое разделение кластера; имена и квоты действуют в пределах namespace |
| netplan | Инструмент настройки сети в Ubuntu, конфигурация в YAML в `/etc/netplan/` |
| Node | Машина кластера; здесь единственный сервер |
| Pod | Минимальная единица развёртывания: один или несколько контейнеров с общей сетью и томами |
| Prometheus | База временных рядов, собирающая и хранящая метрики |
| Promtail | Агент, отправляющий логи контейнеров и системы в Loki |
| ProxyJump | Опция SSH (`-J`): подключение к цели через промежуточный хост |
| PV / PVC | PersistentVolume и PersistentVolumeClaim: хранилище и запрос Pod на него |
| Remote-SSH | Функция IDE: открыть и редактировать папку на удалённой машине по SSH |
| Обратный SSH-туннель | Соединение, открытое с сервера к VPS, которое делает порт сервера доступным на VPS |
| rfkill | Утилита для просмотра и переключения аппаратных и программных блокировок радиомодулей |
| Samba (SMB) | Протокол и сервер сетевых папок, доступных из macOS и Linux |
| Secret | Объект Kubernetes для чувствительных значений, например паролей |
| Service | Стабильный внутренний адрес и балансировщик перед набором Pod |
| SFTP | Передача файлов поверх SSH |
| sshd_config | Файл конфигурации сервера OpenSSH (`/etc/ssh/sshd_config`) |
| Starship | Кроссшелловое приглашение, показывающее контекст git, Kubernetes и др. |
| systemd | Init-система и менеджер служб; запускает юниты, например службу туннеля |
| Traefik | Ingress-контроллер и reverse proxy, входящий в K3s |
| UFW | Uncomplicated Firewall: надстройка над iptables/nftables |
| VPS | Виртуальный сервер в аренду у облачного провайдера, обычно с фиксированным публичным IP |
| YAML | Формат данных на отступах, используется в манифестах и netplan |
