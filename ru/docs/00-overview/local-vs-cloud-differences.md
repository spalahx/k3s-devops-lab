# Локальный сервер и облако: различия

Один и тот же стек работает на домашнем мини-ПК и на облачном VPS. Здесь перечислено, чем они отличаются и какие шаги пропустить или изменить.

## Сравнение

| Аспект | Домашний мини-ПК | Облачный VPS |
|---|---|---|
| Установка ОС | USB-флешка, установщик на консоли | Образ Ubuntu Server LTS выбирается в панели провайдера |
| Адрес | LAN-адрес от роутера; нужно DHCP-резервирование или статика в netplan | Публичный статический IP от провайдера |
| Роутер | Нужен: резервирование, при необходимости проброс портов | Не используется |
| Firewall | UFW на хосте; NAT роутера добавляет ещё один слой | UFW на хосте плюс облачный firewall провайдера (одинаковые порты открыть в обоих) |
| Wi-Fi | Возможен, но лучше Ethernet | Неприменимо |
| Доступ | Из LAN напрямую; снаружи только через VPS-шлюз или проброс портов | Напрямую из интернета, SSH только по ключам |
| DNS и домены | Записи в `/etc/hosts` или локальный DNS (имена `*.local`) | Настоящие A-записи на IP VPS; возможны TLS-сертификаты |
| Питание и стоимость | Покупка железа, электричество, ИБП по желанию; круглосуточная работа при малом энергопотреблении | Ежемесячная плата по CPU/RAM; железа нет |
| Риск | Низкий, пока порты не проброшены | Высокий с первой минуты: боты сканируют новые IP, харденинг делается раньше всего |
| Ресурсы | Определяются вашим железом | Можно менять тариф; локальные LLM обычно слишком дороги |

| [Docker](../03-containers-and-k3s/docker-install.md), [K3s](../03-containers-and-k3s/k3s-install.md) | Выполнить | Выполнить |
| [Ingress и первое приложение](../03-containers-and-k3s/ingress-traefik-first-app.md) | Имена через hosts | Вместо записей в hosts использовать настоящие DNS-записи |

| [Мониторинг](../08-monitoring/helm-basics.md) | Выполнить | Выполнить; следить за памятью на малых тарифах |

> **Warning:** На VPS не закрывайте единственную SSH-сессию, пока меняете порт SSH или правила UFW. Откройте вторую сессию и проверьте новые настройки до выхода; иначе восстановление возможно только через веб-консоль провайдера.
