# Требования и переменные

Оборудование, софт и аккаунты, необходимые до начала, а также все плейсхолдеры, используемые в документации. При копировании команд замените плейсхолдеры своими значениями.

## Оборудование

| Параметр | Минимум | Комфортно |
|---|---|---|
| CPU | 2 ядра, x86_64 или arm64 | 4+ ядер |
| RAM | 4 ГБ (один K3s занимает около 1 ГБ) | 16 ГБ+ (несколько проектов, мониторинг) |
| Диск | 40 ГБ SSD | 250 ГБ+ SSD |
| Сеть | Проводной Ethernet | Ethernet, роутер с DHCP-резервированием |
| Локальные LLM (опционально) | 16 ГБ RAM | 32 ГБ+ RAM или поддерживаемая GPU |

Для сервера лучше Ethernet, а не Wi-Fi (см. [Диагностика сети](../99-appendix/troubleshooting-networking.md)).

## Софт и аккаунты

- Для локального железа: USB-флешка (8 ГБ+) и утилита записи ISO; для VPS — образ Ubuntu Server LTS у провайдера.
- Ноутбук с терминалом и `ssh` (macOS или Linux), IDE с поддержкой Remote-SSH.
- Аккаунт на Git-хостинге (GitHub или GitLab); по одному на каждую личность, если рабочее и личное разделяются.
- Опционально: VPS с публичным IP (удалённый доступ), домен (публичные сайты), container registry.

## Плейсхолдеры

| Плейсхолдер | Значение | Пример |
|---|---|---|
| `<SERVER_USER>` | Обычный пользователь с sudo на сервере | `dev` |
| `<SERVER_HOSTNAME>` | Имя хоста сервера | `devbox` |
| `<SERVER_IP>` | Адрес сервера в LAN (или публичный IP VPS) | `192.168.1.50` |
| `<SSH_PORT>` | Нестандартный порт SSH, выбранный при харденинге | `2222` |
| `<DOMAIN_BASE>` | Базовый домен или локальный суффикс для имён проектов | `devbox.local`, `example.com` |
| `<PROJECT_NAME>` | Короткое имя проекта в нижнем регистре: папка, namespace, имя хоста | `blog` |
| `<VPS_IP>` | Публичный IP VPS-шлюза | `203.0.113.10` |
| `<GIT_WORK_EMAIL>` | E-mail для рабочих коммитов | `me@work.example` |
| `<GIT_PERSONAL_EMAIL>` | E-mail для личных коммитов | `me@home.example` |
| `<DB_PASSWORD>` | Пароль БД, который вы генерируете (`openssl rand -base64 24`) | в репозиторий не попадает |
| `<PROJECT_GROUP>` | Каталог-группа проектов (компания, клиент, `personal`) | `personal` |
| `<DB_NAME>` | Имя базы данных | `wordpress` |
| `<OLD_DOMAIN>` | Домен переносимого сайта | `old.example.com` |
| `<GIT_USER_NAME>` | Имя для коммитов | `Jane Doe` |
| `<ORG>`, `<REPO>` | Организация/пользователь Git и имя репозитория | `acme`, `blog` |
| `<VPS_USER>` | Администратор на VPS-шлюзе | `admin` |
| `<TUNNEL_USER>`, `<TUNNEL_PORT>` | Ограниченный пользователь на VPS и порт, который слушает туннель | `tunnel`, `2200` |
| `<GRAFANA_ADMIN_PASSWORD>`, `<SAMBA_PASSWORD>` | Пароли, которые вы генерируете | в репозитории не хранятся |

Правила именования: `<PROJECT_NAME>` должно быть допустимым именем Kubernetes (строчные буквы, цифры, `-`). Используйте одно и то же имя для каталога с кодом, каталога манифестов, namespace и имени хоста.
